CREE LEARNING STUDIO – INTERACTIVE BODY PARTS

UPLOAD TO GITHUB
1. Download and extract the ZIP.
2. Open your repository: shirinaevans-png/n-hithaw-win-n-hiyaw-win-Learning-Studio
3. Upload body-parts.html, body-parts.css, body-parts.js and the assets folder at the ROOT of the repository.
   IMPORTANT: Keep the image at assets/body-parts-poster.png.
4. Commit changes. GitHub Pages may take a few minutes to update.
5. Open your lesson:
   https://shirinaevans-png.github.io/n-hithaw-win-n-hiyaw-win-Learning-Studio/body-parts.html

OPTIONAL HOME PAGE LINK
In index.html, add a link to the page in the desired section:
<a href="body-parts.html">Interactive Body Parts in Cree</a>

WHAT THIS DOES
- Displays the illustrated poster with clickable numbered body markers.
- Displays selectable English/Cree vocabulary.
- Includes a 12-question, two-direction multiple-choice quiz with score and retry.
- Works entirely offline and on GitHub Pages, no API required.
- Does not overwrite any existing pages, unless you already have files with these exact names.

LANGUAGE NOTE
Words were copied from the example illustration supplied by the user; spellings and dialect-specific forms are not independently verified for Lac La Ronge TH Cree. Verify against the appropriate TH sources before representing them as validated. No synthesized speech or syllabics is included.
