# GiellaLT integration pathway (not yet installed)

The current GitHub Pages site searches locally stored word forms and does not run GiellaLT. The GiellaLT Plains Cree source is https://github.com/giellalt/lang-crk. A live full-paradigm generator requires (1) checking licenses and compiling a Plains Cree HFST generator, (2) deploying it behind an API with access control, limits, and CORS or using a compatible offline browser runtime, (3) mapping the UI person/order tags to documented generator tags, (4) regression-testing forms against published paradigms and Cree language specialists. The Plains generator must not be applied unmodified to Woodland (TH) or Lac La Ronge regional forms. Full sentence grammar checking also requires parsing and validated grammar constraints; morphological recognition alone does not establish grammaticality.
