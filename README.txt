LINGUISTIC CAUTION:
The full sequence from 1 to 2,000 is navigable, but only attested numeral forms are labelled 'Source-listed.' Other numbers display separately sourced component words with an explicit verification warning. Do not treat these components as finished translations. Woodland (TH) reference forms are not independently verified against Lac La Ronge community speech. Syllabics omitted for unverified compounds.
