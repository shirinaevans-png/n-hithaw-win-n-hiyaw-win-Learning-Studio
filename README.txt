SASKATCHEWAN INDIGENOUS PLACE NAMES – GITHUB MAP UPDATE

Upload saskatchewan-cree-map.html and cree-place-names.html to the root of your GitHub Pages repository.
The CSV is optional research data and can be uploaded if desired.
Your existing homepage index.html does not need to be replaced if its navigation buttons already point to these filenames.

The 34 entries are from the existing published-source list: 27 northern Saskatchewan Cree place-name pairings and 7 Cree-derived official names (etymologies). Not all are plotted: those without matched approximate coordinates stay visible in the list and use an OpenStreetMap lookup on click. Map coordinates are preliminary study locators, NOT official point data.

The 2017 Coming Home map is linked as an important reference. Its use terms prohibit reproducing community-provided names without permission. No direct transcription of that map is included. Additional languages must be added using independently licensed or permissioned sources (e.g. federal NRCan Indigenous geographic names open data).

The base map is OpenStreetMap and needs internet access. No GIS mapping libraries are bundled; Leaflet is loaded via CDN.
