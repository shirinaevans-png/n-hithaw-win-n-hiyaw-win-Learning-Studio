Documented Cree place names, language-derived names and First Nations community names

Search recorded Cree place names and other Saskatchewan Indigenous names. Each entry identifies its evidence type and links to a source. An official English-language community name is not presented as a Cree translation.

The federal database includes many Indigenous-derived official names, not necessarily traditional names in Indigenous orthography. This catalogue keeps traditional Cree place-name pairings, Cree-language origins, and official Indigenous community names awaiting linguistic documentation distinct. The dialect is shown only when explicitly documented.

Add records from Canada's Indigenous Geographical Names dataset

Natural Resources Canada publishes an open-licensed national CSV dataset that includes official names, coordinates and Indigenous language of origin where known. To view its Saskatchewan records alongside this list, download the official CSV ZIP, extract the CSV, and select it below. This takes place in your browser; the file is not uploaded to a server.
