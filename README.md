# nîhithawîwin | nêhiyawêwin Learning Studio

IED 501 Final Project. Contains **1,905 searchable entries** from the supplied research spreadsheet. All major vocabulary categories are included, not a 60-word sample. The top selector defaults to **All vocabulary**. Use the **Pronouns & person words** topic filter for person expressions and pronouns. Search matches Cree, English, grammatical class, and category. Matching results render 100 at a time for performance, with a Show More button; searches cover all 1,905.

## GitHub Pages deployment
Unzip and upload **all files** into the existing repository root, replacing existing same-named files, especially `data.js`, `app.js`, `index.html`, `builder.html`, and `dictionary-explorer.js`. Keep the JS and CSS files together. The site runs without a build process.

## Editorial / linguistic note
The broad vocabulary comes from source-coded workbooks and includes dictionary forms as well as words/phrases; it is not a root-word list. **The broad dictionary is not automatically tagged TH or Y.** Separate morphology/VTA lessons contain dialect-specific examples. No automatic blanket grammatical transformations are guaranteed for every dictionary form. Check rights and acknowledgments before posting a full extracted textbook glossary publicly.

## Learner experience
All searchable entries are bundled in `data.js`. Learners do not upload, import, or manage files. Only the site owner updates the repository.
