# Conjugation Engine

Start with conjugation.html, or use the link at the top of every site page. Woodland and Plains records remain separate. This is a **source-constrained conjugation engine**: a selected existing form is verified against the workbook row; a freeform stem combination is always labelled experimental. It does not claim universal grammatical validation.

Source: user-supplied Plains Cree Verb Rule Matrix / Noun Rule Matrix and the previously compiled Woodland Cree example records.

To publish: upload all extracted website files to the GitHub Pages repository root, including conjugation.html, conjugation.css, conjugation.js and conjugation-data.js.
