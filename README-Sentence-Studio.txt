CREE LEARNING STUDIO - SENTENCE STUDIO EXPANSION

Upload verified-sentences.js to the ROOT of your existing GitHub repository,
replacing only the file with exactly the same name.

Do NOT delete or replace builder.html, sentence-studio.js,
conjugation-data.js, your vocabulary files, or any other existing file.

How it works:
- Preserves the current 10 documented Plains Cree examples.
- Automatically adds all uniquely spelled, sourced conjugation/word forms
  already present in your site's CREE_CONJUGATION_RECORDS collection.
- Includes Woodland TH records only when the record explicitly says woodland,
  and Plains Y records only when the record explicitly says plains.
- Uses the original source labels and English glosses.
- Adds single-word inflection exercises as practice; it does NOT generate
  or certify new multiword sentences or grammatical constructions.

Open builder.html on GitHub Pages and visit Sentence Studio.
Under the documented examples dropdown you'll see a larger collection.
These are examples AND recorded practice forms, not all full sentences.

If the page still shows the previous list, hard-refresh with Ctrl+Shift+R.

Caution: the existing 'Check word forms and sentence patterns' interface says
'Source-attested' for exact matches. In this expanded collection, that indicates
only that a stored word form has a cited source, NOT that a full sentence was
independently attested. Original ten examples retain their original citations.

For genuine sentence-pattern generation, an independently reviewed corpus with
clause-level annotations for dialect, verb agreement and word order is needed.
